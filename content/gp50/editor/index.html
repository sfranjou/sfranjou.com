Help

Connect & edit
  • Close Valeton Suite
  • Connect by USB, click Connect pedal and allow MIDI access, including SysEx.
  • Connecting reads the current settings and preset names. The editor checks for pedal changes while the page is visible and idle.
  • Edits take effect on the pedal as you make them. Export a backup before editing.
Browsers
  • Use the demo and work with preset files without a USB connection.
  • Connect over USB in Chrome, Edge or desktop Firefox.
Save & recover
  • Export a .prst backup before overwriting a preset.
  • If the pedal stops responding, the editor disconnects. Check the pedal and reconnect.
  • Use the firmware installer to prepare an update.
  • LTTC playback and CPU load readings require Peppercorn firmware.
  • Click Refresh to read the current settings from the pedal.
