Troubleshooting and recovery

What if my GP-50 freezes?

Hold SAVE + EXIT + GLOBAL together for more than two seconds to force it off. Then hold SAVE + GLOBAL to turn it back on. Unsaved changes may be lost. Keep power and USB connected while a firmware update is in progress.

What if it still won’t boot?

  1. With the GP-50 off, hold both footswitches (A and B) and press and hold the PARA knob.
  2. Connect the 9V power supply while holding all three. Release them when Firmware Update/Restore appears.
  3. Connect the pedal by USB and use desktop Valeton Suite’s Firmware Update to install the official GP-50 V1.1.0 file. Keep the pedal connected until the update finishes.

If the pedal starts normally and you just want to return to stock, install the same official file in Valeton Suite from normal mode.
